# Endfield preset

The Arknights: Endfield resource repository for a certain mod manager.

> **Not tested in game yet.** Some mods may be filed in the wrong place.

This repository, the builder included, was entirely vibe coded: written with AI assistance.

## Installing it

Add this address as a pack source in the mod manager's settings:

```
https://raw.githubusercontent.com/dotStray/endfield-preset/main/index.json
```
